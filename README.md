# Shipaton 2026 — Mobile Game

A mobile game developed for the RevenueCat Shipaton 2026 hackathon.

## Project

A mobile gaming experience designed around short, satisfying and replayable sessions, with progression, retention and a sustainable monetization strategy.

## Goals

* Create an excellent mobile game.
* Integrate RevenueCat.
* Develop a strong monetization strategy.
* Build and document the project publicly.
* Implement retention mechanisms.
* Launch the game during the Shipaton 2026 submission period.

## Technology

* Unity
* C#
* Android
* RevenueCat
* OneSignal
* Git / GitHub

## Status

Pre-production.

The game concept and core gameplay are currently being defined.
